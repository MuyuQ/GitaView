- Rust 共享核心；macOS SwiftUI / 必要的 AppKit；Windows C# + WinUI 3。

- 主应用存活才扫描；显式退出停止；系统组件消费历史安全快照。
- Pull / Push 必须确认；固定 Git 参数；自动刷新不 Fetch。
