## 决策摘要

- Rust 共享核心；macOS SwiftUI / 必要的 AppKit；Windows C# + WinUI 3。
- 系统组件为 WidgetKit / Windows Widget Provider，首版全部仓库摘要与关注列表。
- 不做旧数据迁移、旧安装升级或历史 JSON / IPC 兼容。
- 不实现 WorkerW / Progman / 特殊桌面层；主应用 UI 在旧版基础上统一升级，两端共用布局与视觉设计，系统装饰与原生能力允许差异。
- 旧 Tauri 客户端不接入新核心，保留作参考。
- 新协议 gitaview-native，新身份 / 新数据目录；真实签名标识待环境核对。
- 主应用存活才扫描；显式退出停止；系统组件消费历史安全快照。
- Pull / Push 必须确认；固定 Git 参数；自动刷新不 Fetch。
